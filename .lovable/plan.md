# Publish Footy KPI to a Live Website

## What this plan does
Rename the app from AthleteFolio to Footy KPI, then publish the project so it becomes accessible on the public web.

## Steps
1. Update app name and metadata from "AthleteFolio" to "Footy KPI" across the root route (title, description, OG/Twitter tags, headings where shown).
2. Run a security scan and resolve any blocking critical findings.
3. Publish the project via Lovable's publish flow.
4. Confirm the live URL and share it.

## Optional follow-up
- Connect a custom domain (e.g. `footykpi.com`) from Project Settings → Domains once the app is live at the Lovable URL.

## Outcome
The app is publicly available at a stable Lovable URL under its new name, Footy KPI, ready to share with players, coaches, and recruiters.
