# Footy KPI

We're not building a stat tracker—we're building a digital athletic portfolio for youth athletes. Every game becomes part of a player's permanent history, combining stats, photos, videos, achievements, and verified performance into one profile they can share with family, coaches, and eventually recruiters. The MVP focuses on making game tracking effortless, visually engaging, and easy to share. Once we validate demand, we'll expand into coach dashboards, club management, AI performance insights, and recruiting tools.
